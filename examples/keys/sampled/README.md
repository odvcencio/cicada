# Sampled keys demos

Generate the pinned banks with the [owned keyboard pack instructions](../../../assets/keys/README.md), then copy these scores beside the generated `packs/` directory. Each standalone score contains two bars of comping and two bars of melody at tempo 108. All manifest hashes are pinned.

Each comping voice has its own monophonic score track. The four parts preserve the modeled phrase's notes, gates, and timing, with eight total sampler slots. The melodic scene uses the first part. Native Studio opens these files and plays the prepared sampler banks; browser/game playback uses the optional sampler host.
