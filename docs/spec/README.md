# Cicada language reference

This reference describes source editions 1 and 2 and their typed project model. New projects use edition 2, which retains edition-1 meanings and requires named mixer spellings.

Go tests validate every runnable `cicada` example in this reference, the manual, and the repository README. `cicada-invalid` examples must produce their named diagnostic. Every example selects edition 2.

The appendix is generated by `go generate ./language/grammar`. `TestDocumentationEBNFMatchesGrammarDSL` compares the complete generated appendix with `language/grammar/grammar.go`, including precedence and lexical priority documentation.
